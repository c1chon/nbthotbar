# Cursed Hotbar

A Minecraft saved hotbar (`hotbar.nbt`) full of cursed items made with NBT data. Load it in Creative mode and get the whole set instantly.

> **Warning:** These items are cursed on purpose. Some may be weird, broken, or laggy. Use at your own risk, preferably in a throwaway world.  
## Requirements

- Minecraft Java Edition 
- Creative mode (saved hotbars only work there)

## Installation

1. Close Minecraft.
2. Download `hotbar.nbt` from this repo.
3. Put it in your game or instance folder, next to `options.txt` and `servers.dat`. Replace the existing file if there is one (back it up first).
   - **Vanilla launcher:** `.minecraft/`
   - **Modrinth App (Flatpak on Linux):** `~/.var/app/com.modrinth.ModrinthApp/data/ModrinthApp/profiles/<instance name>/`
4. Launch the game.

## Usage

1. Join a world in **Creative mode**.
2. Press `C` + the hotbar number (`1`-`9`) to load the saved hotbar.

> Tip: if the keys do nothing, check **Options → Controls → Key Binds → Miscellaneous** for the "Load Toolbar Activator" binding.

## Making your own

Press `X` + a number key in Creative mode to save your current hotbar into that slot. The result is written to `hotbar.nbt`.
